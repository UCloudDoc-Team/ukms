为确保服务性能和业务稳定性，UCloud API 针对不同用户在不同地域发起的 API 请求设置了相应的频率限制策略。当响应结果包含 RequestLimitExceeded 错误码时，表明当前请求已超出接口频率限制。KMS 的 QPS 配额限制，请参考 [API 概览](/api/API%20概览.md)。
