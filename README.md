# UCloud 密钥管理服务（UKMS）

UCloud 密钥管理服务（UKMS，UCloud Key Management Service）是一项托管式密钥管理服务，让您可以轻松创建和管理加密密钥，控制密钥在各种云服务和应用程序中的使用。

UKMS 使用第三方认证的硬件安全模块 HSM（Hardware Security Module）来生成和保护密钥，满足用户多应用多业务的密钥管理需求，助力用户落实合规要求。
